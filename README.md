### 📜 The Code

- One does not simply push to `main`.
- Never tell me the odds. Show me the test that fails without the fix.
- `terraform apply` without reading the plan is how the Death Star got its exhaust port.
- If it isn't in version control, it doesn't exist.
- Don't panic, and always know where your towel (and your backups) are.
